# MuletAí

A ideia principal do **MuletAí** é conectar pessoas que possuem equipamentos médicos para doação como muletas, andadores, cadeiras de roda, camas hospitalares a quem depende deles.
Como requisito de pagamento, o sistema possui um sistema de contribuição para compra de equipamentos não disponíveis, qualquer um pode ajudar com a quantia que lhe é conviniente.
